# OpenVTC Documentation

Project documentation for OpenVTC. User-facing operational docs live in the
crate READMEs and the repo root `README.md`; this tree holds deeper material.

- [`design/`](./design/) — design thinking: specifications, architecture
  decisions, and proposals.
- [`community-rooms.md`](./community-rooms.md) — a community's data rooms: how
  OpenVTC, the member portal and `pnm` show the same rooms in the same state.
- [`forge-accounts.md`](./forge-accounts.md) — choosing which forge account
  (gh account or SSH key) a community's repositories clone, fetch and push
  with.
